# Лабораторная работа №1 - вариант 4

## Условие

Написать на Си две программы: родительскую и дочернюю. Первой строкой
пользователь вводит имя выходного файла. Родитель передаёт его дочерней
программе при запуске, а следующие строки отправляет ей через канал.

В каждой строке может быть сколько угодно чисел типа `float`. Дочерний
процесс делит первое число на второе, полученный результат на третье
и так далее. Итог каждой строки он записывает в файл. Если делитель
равен нулю, дочерний процесс сообщает об этом родителю через второй
канал, и оба процесса завершаются.

## Сборка и запуск в Linux

1. Открыть терминал Linux (подойдёт Ubuntu в WSL).
2. Если компилятор Си и `make` не установлены, установить их.
   Для Ubuntu: `sudo apt install build-essential`.
3. Перейти в папку `Лаба1` и выполнить:

   ```sh
   make
   ./parent
   ```

Команда `make` собирает обе программы: `parent` и `child`. Вручную
запускать только `./parent`: она сама запустит `./child`. Если оба файла
уже собраны под используемую систему, `make` можно пропустить.

Для запуска готовой Linux-версии через WSL открыть PowerShell в папке
`ЛабыОС` и выполнить:

```powershell
$lab = (Resolve-Path -LiteralPath '.\Лаба1').Path
wsl --cd $lab -- ./parent
```

Для Windows без WSL есть [отдельная версия с инструкцией](Windows/README.md).

## Пример

Программа ждёт ввод сразу после запуска. Ввести имя файла, а затем
по одной команде на строку. В дробных числах использовать точку.

```text
result.txt
100 2.5 4
-10 4
0 3
```

Для завершения ввода в Linux нажать **Ctrl+D** на пустой строке.
В файле `result.txt` появится:

```text
10
-2.5
0
```

В первой строке программа считает `(100 / 2.5) / 4`. Ноль в начале
строки допустим: ошибка возникает только на нулевом делителе.
Например, после строк `8 2`, `9 -0.0`, `12 3` в файле останется только
`4`, а программа завершится с кодом `2`. При неверном числе или системной
ошибке код завершения будет `1`.

Выходной файл создаётся в текущей папке, если указано только его имя.
Если файл уже существует, программа его перезапишет.

## Как это работает

Родитель создаёт два канала через `pipe()`, а затем запускает дочернюю
программу через `fork()` и `execve()`. С помощью `dup2()` первый канал
подключается к стандартному вводу дочернего процесса, второй к его
стандартному выводу. По первому идут команды, по второму возвращаются
статусы. Сами результаты дочерний процесс пишет прямо в файл.

При конце ввода родитель закрывает пишущий конец канала команд.
Дочерний процесс дочитывает данные и получает EOF, а родитель через
`waitpid()` дожидается его завершения. Если делитель оказался нулём,
родитель узнаёт об этом из обратного канала и не ждёт следующую строку.

Для ввода и вывода используются `read()` и `write()`. Числа программа
разбирает и форматирует сама, без `stdio.h`, `scanf()` и `printf()`.
