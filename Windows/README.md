# Лабораторная работа №1 - вариант 4 (Windows)

## Условие

Пользователь вводит имя выходного файла, а потом строки с числами типа
`float`. Родитель запускает отдельную дочернюю программу, передаёт ей
имя файла при запуске и отправляет строки с числами через канал.
Дочерний процесс делит первое число в строке по очереди на все остальные
и записывает итог в файл. Чисел может быть сколько угодно. Если делитель
равен нулю, дочерний процесс сообщает об этом родителю по второму каналу,
и оба процесса завершаются.

## Запуск

Готовые файлы `parent.exe` и `child.exe` работают на 64-битной Windows
без WSL и компилятора. При переносе на другой компьютер положить оба
файла в одну папку.

1. Открыть папку с программами в Проводнике.
2. Ввести `powershell` в адресной строке и нажать Enter.
3. В PowerShell выполнить:

   ```powershell
   .\parent.exe
   ```

## Пример

Программа ждёт ввод сразу после запуска. Ввести строки из примера,
нажимая Enter после каждой:

```text
result.txt
100 2.5 4
-10 4
```

Для завершения ввода нажать **Ctrl+Z**, затем **Enter** на пустой строке.
В файле `result.txt` появятся две строки: `10` и `-2.5`. Если файл
уже есть, он будет перезаписан. В дробных числах использовать точку.

При делении на `0` или `-0.0` программа завершится с кодом `2`.
Результаты предыдущих строк останутся в файле. При неверном числе
или системной ошибке код завершения будет `1`.

## Сборка из исходников

Для запуска готовых `.exe` сборка не нужна.

1. Установить 64-битный MinGW-w64 GCC и проверить, что команда
   `gcc --version` работает в PowerShell.
2. Перейти в папку `Windows` и выполнить:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\build.ps1
   ```

Скрипт соберёт `parent.exe` и `child.exe` рядом с исходниками.
После сборки запускать только `parent.exe`.

## Чем отличается от Linux-версии

Вместо `fork()` и `execve()` используется `CreateProcessW()`, а
вместо `pipe()` используется `CreatePipe()`. Дочерний процесс открывает
файл через `CreateFileW()` и пишет в него через `WriteFile()`.
Родитель дожидается дочернего процесса через `WaitForSingleObject()`.
Сам порядок вычислений одинаков в обеих версиях.
